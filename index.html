A hybrid LightGBM-Optuna algorithm for road accident severity classification, United States 2016–2020

Soheil Rezashoar, Ehsan Kashi and Soheila Saeidi. Innovative Infrastructure Solutions 9, 319 (2024). doi.org/10.1007/s41062-024-01626-y

Method

The paper predicts the severity of a road accident (1 = least, 4 = most impact on traffic) from location, time, weather and road features. This repository implements the same steps.

Data

US-Accidents (Moosavi et al.), February 2016 to December 2020, 49 states.

Preprocessing

Time variables, missing values by weather station and month, grouped weather and wind, Box-Cox, frequency and one-hot encoding.

Sampling

14,800 / 248,000 / 148,000 / 48,000 records of severity 1 to 4; 67 % training, 33 % testing.

Optuna

11 hyperparameters, 50 trials, stratified 10-fold CV, multi-class log loss, pruning.

LightGBM

400 trees with the best hyperparameters; evaluated with accuracy, precision, recall, F1 and ROC-AUC.

Data and limits of the demo

    To reproduce the paper exactly, use the December 2020 release of US-Accidents (about 4.2 million records) with the class sizes above. It is not included here because of its size and licence.

    Run it

    pip install -r requirements.txt
python src/preprocess.py --input data/US_Accidents_Dec20.csv --output data/model_table.csv.gz
python src/tune.py  --data data/model_table.csv.gz --out results/run --trials 50 --folds 10
python src/train.py --data data/model_table.csv.gz --params paper --out results/run_paper
python src/train.py --data data/model_table.csv.gz --params results/run/best_params.json --out results/run_tuned
